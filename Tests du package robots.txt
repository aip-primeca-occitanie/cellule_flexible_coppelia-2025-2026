Tests du package robots :

1) Prérequis
On doit avoir lancé dans un terminal (1) dans ros_ws:
       source /opt/ros/jazzy/setup.bash
       colcon build
       source install/setup.bash
       ros2 run robots robot 2
On doit avoir un autre terminal (2) dans ros_ws prêt :
       source /opt/ros/jazzy/setup.bash
       source install/setup.bash
       
2) Test OK du Shutdown
EXPLICATIONS : Le but est de tester que la simulation se ferme bien lorsqu'on lui en donne l'ordre.
TEST : On remplace la ligne "ros2 run robots robot num_robot" par "ros2 launch robots robotsGauche.launch.py". Dans le terminal 2, on envoit "ros2 topic pub -n temp_pub --once /commande_locale/shutdown std_msgs/msg/Byte "{}""
RESULTAT : On doit voir les deux fenêtres des robots se fermer (terminal 1) et voir apparaitre des messages "process has finished cleanly" (terminal 1)
Rq : Refaire "ros2 launch robots robotsGauche.launch.py" dans le terminal 1 pour revenir à l'état initial.

3) Test KO de l'initialisation (choix du robot)
EXPLICATIONS : Il y a 4 robots différents. Nous devons donc choisir un numéro de robot compris entre 1 et 4. Si num_robot est 1, 2, 3 ou 4, la simulation doit s'ouvrir correctement (directement dans le terminal). Si num_robot est invalide, la simulation renvoit CHOIX ROBOT INCORRECT.
TEST : Dans le terminal 1, on remplace "ros2 run robots robot 2" par "ros2 run robots robot 8".
RESULTAT : La console affiche "CHOIX ROBOT INCORRECT".

4) Protocole pour finir l'initialisation //Pas besoin si lié à Coppelia, besoin si testé individuellement
EXPLICATIONS : Pour terminer l'initialisation, nous avons besoin d'avoir tous les handles du robot. On demande donc à Coppelia de nous les envoiyer. Comme Coppelia n'est pas encore présent, on simule sa réponse par une publication sur le bon topic. 
TEST : Dans le terminal 2, faire "ros2 topic pub --times 7 /sim_ros_interface/services/response/robot2/GetObjectHandle std_msgs/msg/Int32 "{data: 1}""
RESULTAT : La console affiche "Robot 2 OK"

4) Test OK de la fonction Evacuer
EXPLICATIONS : On souscrit dans l'initialisation au topic "/commande/Simulation/Evacuer", de format Byte, qui exécute si activé la fonction Evacuer (dans Robot). On vérifie donc qu'en publiant un message sur ce topic, la fonction Evacuer s'effectue correctement.
TEST : (tout dans le terminal 2)
	4.1) Pour rentrer dans la fonction (publier un message sur le topic), on fait : "ros2 topic pub -n temp_pub --once /commande/Simulation/Evacuer std_msgs/msg/Byte "{}""
	4.2) Ensuite pour sortir du premier while : "ros2 topic pub --times 6 /sim_ros_interface/services/response/robot2/GetColor std_msgs/msg/Int32 "{data: 1}""
	4.3) Pour sortir de la fonction Evacuer : "ros2 topic pub -n temp_pub --once /sim_ros_interface/services/response/robot2/ChangeColor std_msgs/msg/Byte "{}""
RESULTAT : (dans le terminal 1)
	Pour le 4.1. nous obtenons "Callback Evacuer recu pour robot 2".
	Pour le 4.2. nous obtenons une liste de couleur "couleur[0]=1, couleur[1]=1, couleur[2]=1, couleur[3]=1, couleur[4]=1, couleur[5]=1"
